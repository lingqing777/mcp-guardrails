📋 配置指引
▾

步骤 1: 修改你的 Cursor/Agent MCP 配置，连接到 MCP Hub：

// ~/.cursor/mcp.json { "mcpServers": { "guardrails": { "url": "http://localhost:4000" } } }

步骤 2: 在 config/mcp-servers.json 中配置你自己的 MCP Server

步骤 3: 你的 MCP Server 需配置 HTTP 代理指向 WAF2：

# 在你的 MCP Server 环境变量中配置 REST_BASE_URL=http://localhost:8081

只需一步：将 MCP Server 的 REST_BASE_URL 改为 WAF2 地址

# 原配置 REST_BASE_URL=http://localhost:3000 # 改为 ↓ REST_BASE_URL=http://localhost:8081
